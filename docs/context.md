## 招聘智能体：优先补的追问

1. 召回率的定义、评测集规模、多路召回各自的贡献、典型失败样本。
2. 语音时延预算、ASR 错误怎么进评分、追问的停止条件。
3. 评分维度、量表、和人工分的对齐方法，以及 <10% 的算法。
4. LangGraph 的状态、节点、重试和人工介入；三个 Agent 的输入输出边界。
5. MCP 接了哪些工具；多跳检索何时停止、证据如何引用、怎样挡住幻觉进录用报告。
6. Celery 慢在哪：队列、序列化、LLM 调用是否堵在 worker、秒级是怎么量的。
7. 钉钉免登、JSAPI、Stream 在生产里接到了哪一步。
8. 80% 和 100+ 人日的计算过程。
